# あわあわ おふろやさん

12のどうぶつを、なでてふわふわに。

**iPhone・iPad向け／300円の買い切り／日本向けに公開準備中**

広告・アプリ内の追加購入・アカウント登録はありません。ゲームはオフラインで遊べます。

## あそびかた

1. お世話したいどうぶつを選びます。
2. 汚れているところを指でなでて、泡で洗います。
3. 自動でシャワーに変わったら、体に水を当てて流します。
4. タオルで水滴を拭き、ドライヤーで残った湿りを乾かします。
5. ふわふわになったら「もういちど」で、好きなどうぶつを選べます。

道具は自動で切り替わります。点数・制限時間・失敗はありません。シャワーは体に水が当たっている時間だけ進みます。

## 音と保護者設定

右上の音のマークで音を切り替えます。選択画面の「保護者」を2秒長押しすると、BGM・効果音・控えめな演出を調整できます。ナレーションはありません。

保護者設定の「プライバシー・お問い合わせ」から、アプリ内のポリシー・遊び方・ライセンスを確認できます。外部サイトを開くときは大人向けの確認があります。

## よくあるご質問

**途中の状態は保存されますか？**

音や演出の設定と、お世話回数を端末内に保存します。アプリを終了して起動し直すと、動物選択から始まります。

**シャワーが進みません。**

体に水が当たるように指を動かしてください。背景への操作や、手を離した時間では進みません。

**追加料金はかかりますか？**

アプリ内の追加購入や広告はありません。購入・返金のお手続きはApp Storeの案内をご確認ください。
